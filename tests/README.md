# Tests to add in later milestones

The first tests will cover per-agent tool allowlists, authorization at both handoff directions and at each tool call, context isolation, quote revalidation, idempotent mock purchases, and outbox replay. The evaluation harness will also run the scenario fixtures in `fixtures/tasks.json`.

Step 2 adds `test_step2.py` for the bounded runtime, role allowlists, handoff and return checks, cross-tenant denial, scope checks, answer repair and sourced fallback, and the purchase stub. Step 3 adds `test_step3.py` for signed-token failures, current scopes, quote ownership and expiry, seller and budget rules, one-charge retries, an attempted concurrent double purchase, the API boundary, the integrated paid path, durable audit, outbox replay, and rollback if an audit write fails. Run `ACS_TEST_POSTGRES_DSN='dbname=agent_commerce_security_test' .venv/bin/python -m unittest discover -s tests -v`. `test_step3_postgres.py` checks atomic purchase, retry, concurrent budget use, tenant, scope, and outbox deduplication only in the dedicated `agent_commerce_security_test` database. The sink is local, and a broader evaluation harness remains to be built.
